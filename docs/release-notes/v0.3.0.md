## ASAP 0.3.0 — Agent Supervision & Approval Platform

> Agent yang kerja, kamu yang approve. Beres ASAP.

Rilis pertama dengan nama **ASAP** (sebelumnya *ADE*).

### Yang baru
- **Rebrand + ikon baru** — nama ASAP, ikon monogram garis lengkung beraksen biru.
- **Pohon file** di kolom ke-3 — jelajahi repo terpilih atau worktree task, tanda status git A/M/D, filter nama file.
- **Terminal terintegrasi** (`›_ Terminal` / Ctrl+`) — PowerShell interaktif di folder repo/worktree, multi-tab.
- **Mode fokus** (⤢) — satu kartu tampil selebar layar, Esc untuk kembali.
- **Tab Git** — graph commit (cabang/merge, label branch/tag, semua branch), detail commit + diff,
  stage/unstage per file, commit (Ctrl+Enter), indikator ↑ahead ↓behind. Push/pull tetap lewat terminal.
- **Badge Brain Vault** — file simlab-v2 menampilkan status hotspot + riwayat bug (kalau vault ada di laptop).
- **Syntax highlighting** (PHP, Blade, JS/TS, SQL, CSS, dll) dan **cari di file** (Ctrl+F).
- **`npm test`** — tes otomatis protokol sidecar + UI (untuk pengembang).

### Pasang
1. Kalau sudah memasang **ADE 0.2.0**, uninstall dulu (nama aplikasi berubah). Data
   (`%APPDATA%\ade`: folder, task, riwayat keputusan) tetap aman.
2. Unduh dan jalankan `ASAP_0.3.0_x64-setup.exe` — per-user, tanpa admin.
3. Kalau header menampilkan *Belum login Claude*, klik untuk login dengan akun Claude masing-masing.

Paket sudah berisi Node, sidecar, dan mesin agent — tidak perlu memasang Node / Claude Code.
Kuota agent memakai langganan Claude milik akun yang login.
